# Contributing guidelines

At OpenStud, we love that others would like to contribute to our silly lil' game.

But, before you do, please follow these 3 rules:

1. AI is allowed, but only a FEW lines. Don't EVER submit AI generated code here!
2. Your code may not compromise ones' computer.
3. Test your code before submitting it here!

By following these rules, you'll be a great contributor to the project!
